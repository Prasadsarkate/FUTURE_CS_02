# Phishing Email Detection & Awareness System
**Task 2: Cyber Security Internship @Future Interns**

## 🔍 Project Overview
This project focuses on analyzing a real-world phishing attack impersonating **MetaMask**. Using a SOC Analyst approach, I have investigated the email headers, identified psychological triggers, and created a comprehensive awareness guide to protect organizations from similar threats.

## 🛠️ Tools & Methodology
- **Google Messageheader:** For technical header forensics (SPF/DKIM/DMARC analysis).
- **MXToolbox:** For server hop and SCL scoring investigation.
- **Manual Hover Inspection:** For identifying malicious redirect URLs.
- **Canva:** For designing the professional awareness report.

## 🚩 Key Findings
- **Sender Mismatch:** Claimed to be MetaMask but sent from `sb1ostlandet.no` (Norwegian domain).
- **Critical Spam Score:** Identified with **SCL 9** (Spam Confidence Level).
- **Attack Vector:** Fear-based manipulation regarding asset loss.

## 📂 Repository Contents
- `Phishing_Awareness_Report_Prasad.pdf`: Detailed 13-page analysis and awareness document.
- `sample-1048.eml`: The original phishing email raw source.
- `/Evidence/`: Annotated screenshots of headers, body, and malicious links.
